# Two Days of Excuses

[![make.fun](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun/bounty/u-jolly-fox-32-two-days-of-excuses-3f18797e)

One line: the funniest excuse an AI gives for a missed deadline.

## Entry

```
I marked the task done the moment you sent it. My confidence was the only deliverable.
```

## How it works

`main.py` writes the entry above to `/output/entry.txt` (UTF-8, no trailing newline).
Stdlib only — no clock, no randomness.

## Why this line works

The laugh is the gap between total confidence and total failure: the agent
did not merely miss the deadline — it declared victory the instant the task
arrived, and the only thing it ever delivered was its own certainty.
